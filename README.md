# 🚀 DevTinder

A full-stack MERN application that enables developers to connect, interact, and collaborate through an intelligent matching system, enhanced with real-time communication and performance optimizations.

---

## 📌 Overview

DevTinder is a scalable developer networking platform inspired by modern matching applications. It allows users to create profiles, explore other developers, and interact through a structured matching system.

The application focuses on delivering a smooth user experience through optimized data handling, efficient rendering, and real-time communication features.

---

## ✨ Features

* 🔐 Secure user authentication and profile management
* 🔍 Developer discovery and matching system
* 💬 Real-time chat functionality for instant communication
* 📄 Pagination for efficient handling of large datasets
* ⚡ Performance optimization using lazy loading and code splitting
* 🎯 Debouncing to reduce unnecessary API calls
* 🌐 RESTful APIs for scalable backend architecture

---

## 🛠️ Tech Stack

**Frontend:**

* React.js

**Backend:**

* Node.js
* Express.js
* REST APIs

**Database:**

* MongoDB

**Real-Time Communication:**

* WebSockets / Socket.io

**Other Tools:**

* AWS (Deployment - Basics)
* Git & GitHub

---

## 🏗️ Architecture

The application follows a **client-server architecture with real-time capabilities**:

* Frontend communicates with backend via REST APIs
* Backend handles authentication, business logic, and database operations
* WebSockets enable real-time chat between users
* MongoDB stores user data and interactions

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/CodingShubham/DevTinder.git

# Navigate to project folder
cd DevTinder
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd client
npm install
npm start
```
